## 剩余发布门槛

1. 在唯一授权主机运行 `tests/isolated_acceptance.sh`，保存完整脱敏输出。
2. 运行锁定主机的 `tests/memory_profiles.sh`，记录真实 Mihomo 64–2048 MiB 档位结果。
3. 运行锁定主机的 `tests/cpu_profiles.sh`，记录测试机真实在线核数范围内的 cgroup CPU quota 结果。
4. 运行锁定主机的 `tests/dns_profiles.sh`，记录公共 DNS 实测保留或系统回退及真实内核解析结果。
5. 使用 `tests/isolated_acceptance.sh` 的独立 Cloudflare 测试参数（不能复用正式 Tunnel）验证公网 WS、断线恢复和吞吐。
6. 若测试机具有公网 IPv6，完成 Reality IPv6 外部网络复核；否则明确记录环境不具备条件。
7. 验收后复核 `FEATURE_GAP.md`，只有全部门槛有当前版本证据时才能标记目标完成。
