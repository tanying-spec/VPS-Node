## 0.2.0-dev.95 待验收变更

- 锁定主机验收器现已实现真实 CDN 公网闭环：七项材料成组校验、正式 Token/域名拒绝、内部端口空闲检查、双映射端口切换、未映射端口失败回滚、删除后的 DNS 与 Origin Rule API 复核，以及不含敏感测试材料的证据字段。默认无凭据路径已在唯一授权主机通过；公网路径仍需独立测试材料。

- 唯一测试机已完成当前脚本的完整 smoke、安装测试和隔离真实内核验收；NAT 记录、链接、成功/失败端口事务及 Cloudflare API 成功/失败/删除路径均在临时目录通过。
- Cloudflare API 使用伪服务证明请求范围和对象 ID 回滚，不等同于真实边缘可达；仍需独立最小权限 Token、Flexible 测试 Zone 和专用子域名完成公网证据。
- Alpine/OpenRC 后台监测安装现在把 `crond` 启动及开机注册纳入同一恢复事务；任何一步失败都会恢复监测文件、原运行状态和原开机状态。
- 首页和稳定性页会核验真实调度状态；首次取消监测安装保持零项目写入，缺失或无效的 CLI 入口会在创建定时任务前被拒绝。
- 分层健康检查和脱敏报告复用同一调度检查，分别提供用户可读的监控层结论及不包含路径/命令内容的机器可读状态。
- 监控运行器和 systemd/OpenRC 定义必须逐字匹配项目生成内容，单独复制所有权标记不能获得覆盖或卸载权限；被修改的定义会保留供人工核对。
- 唯一测试机验收会在临时前缀生成并核验隔离监控运行器和诊断状态，但不会注册 OpenRC 周期任务或改变正式 `crond` 状态。
